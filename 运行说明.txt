银行网点管理系统 —— 运行说明（拿到压缩包后照着做）
==================================================

这是一个 Spring Boot + MySQL 的网页系统。跑起来的必要条件是三样：
  1) 装 Java
  2) 装 MySQL 并导入项目里的 sql/bank.sql
  3) 启动程序，然后用浏览器打开 http://localhost:8080/login

全过程大约 10 分钟，不需要联网下载任何东西（依赖和 jar 都在压缩包里）。


一、先装 Java
--------------------------------------------------
装 JDK 8 或更高版本（推荐 JDK 17 或 21，都向下兼容）。
装完打开命令行（Win+R 输入 cmd 回车），敲：

    java -version

能打印出版本号就算成功。如果提示 "java 不是内部或外部命令"，说明没装好或者
没配环境变量，重装一次并在安装向导里勾选 "Add to PATH"。

（说明：程序编译目标是 Java 8，所以 8 / 11 / 17 / 21 都能跑，不用非得装 8。）


二、装 MySQL 并导入数据
--------------------------------------------------
1. 装 MySQL 5.7 或 8.0（推荐 8.0），安装过程中会让你设置 root 密码，
   **把这个密码记下来，第 4 步要用**。装完确认 MySQL 服务是启动状态。

2. 解压压缩包（建议解压到路径不带中文和空格的目录，例如 D:\bank-system）。

3. 导入数据。在解压出来的项目根目录（能看到 pom.xml、sql 文件夹的那一层）
   打开命令行，执行：

       mysql -uroot -p < sql\bank.sql

   回车后输入你的 root 密码。没有任何输出就是成功了。

   * 也可以用 Navicat / MySQL Workbench 打开 sql\bank.sql 整个执行一遍，效果一样。
   * sql 脚本自己会建库（bank_account_trade）和建表，不用手动建库。
   * 注意：脚本第一行是 DROP DATABASE IF EXISTS bank_account_trade，
     也就是会先删掉同名的库再重建。如果你机器上已经有叫这个名字的库且有数据，
     先备份，或者给它改个名字。


三、如果 MySQL 的 root 密码不是 123456
--------------------------------------------------
程序里写的数据库密码是 123456。密码不一样的话，不用改代码，启动时带一个参数就行
（把 你的密码 换成实际密码）：

       java -jar target\bank-system-1.0.0.jar --spring.datasource.password=你的密码

如果连数据库名或端口也不一样，再加对应的参数（注意这一串要用英文双引号整个包起来，
因为里面的 & 在命令行里是"连接两条命令"的意思，不包起来会被截断）：

       java -jar target\bank-system-1.0.0.jar --spring.datasource.password=你的密码 "--spring.datasource.url=jdbc:mysql://localhost:3306/你的库名?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true"

密码里如果带 & 或空格这类符号，也要用双引号包起来，例如：
       --spring.datasource.password="ab&cd"

（注意：直接改 src\main\resources\application.yml 是没用的，因为配置已经打包进
 jar 里了；除非你重新编译一遍。）


四、启动程序
--------------------------------------------------
在项目根目录执行：

       java -jar target\bank-system-1.0.0.jar

看到最后一行打印 "Started BankApplication in x.x seconds" 就是启动成功。

  * 这个命令行窗口不能关，关掉服务就停了。要停服务就在窗口里按 Ctrl+C。
  * 如果报 "Port 8080 was already in use"，说明 8080 被别的程序占了，
    可以换端口启动：java -jar target\bank-system-1.0.0.jar --server.port=9090，
    然后浏览器访问 http://localhost:9090/login。

如果目录里没有 target\bank-system-1.0.0.jar（压缩包把编译产物去掉了），
那就得自己编译一次：先装 Maven，在项目根目录执行

       mvn -DskipTests package

如果这台机器没网，用它自带的离线仓库编译（.m2repo 文件夹就是干这个的）：

       mvn -DskipTests -Dmaven.repo.local=.m2repo package

成功后再回到上面那条 java -jar 命令运行。


五、用浏览器打开
--------------------------------------------------
地址：http://localhost:8080/login

演示账号（口令全部是 123456）：

     admin      系统管理员，能看到全部菜单
     T2026001   柜员
     C2026001   信贷员
     M2026001   分行经理
     X2026001   风控 / 审计员
     S2026001   客户

不同角色登录后左侧菜单不一样，菜单是数据库配置的，不是写死在页面里的。


六、报错对照表
--------------------------------------------------
"java 不是内部或外部命令"
    → Java 没装或没配 PATH，见第一节。

"Port 8080 was already in use"
    → 8080 被占用。换端口：加 --server.port=9090 参数。

"Communications link failure" / 连不上 3306
    → MySQL 服务没启动。Win+R 输入 services.msc，找 MySQL 服务点启动。

"mysql 不是内部或外部命令"
    → MySQL 的命令行工具没在 PATH 里。用完整路径执行，例如：
      "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -uroot -p < sql\bank.sql
      或者干脆用 Navicat / Workbench 图形界面导入 sql 文件，不用命令行。

"Access denied for user 'root'@'localhost'"
    → 数据库密码不对，按第三节带 --spring.datasource.password 参数启动。

"Unknown database 'bank_account_trade'"
    → sql 没导入成功，回到第二节重做，注意命令行要在项目根目录执行。

"Table 'bank_account_trade.xxx' doesn't exist"
    → sql 只导了一半就中断了。重新完整执行一次 sql\bank.sql。

登录时提示账号或口令错误
    → 口令是 123456（全小写数字），账号区分大小写，例如 T2026001。

页面样式正常但没有数据 / 菜单是空的
    → 数据没导全，重新执行 sql\bank.sql。


七、目录里几个文件夹是干什么的
--------------------------------------------------
    src\              源代码（Java + 页面 + 样式和脚本）
    sql\bank.sql      建库建表 + 演示数据，必须导入
    target\           编译产物，里面的 bank-system-1.0.0.jar 就是要运行的程序
    pom.xml           Maven 配置，用 IDEA 打开这个文件即可导入工程
    .m2repo\          离线 Maven 仓库（在没网的环境下编译时用）。
                      只要你只是运行 jar，这个文件夹用不到，可以删掉；
                      但删了以后就不能在这台机器上离线编译了。
    app.log           程序运行日志，出问题时看这里

用 IDEA 打开：菜单 File → Open，选中项目里的 pom.xml，等依赖加载完，
运行 com.bank.BankApplication 这个类即可（等价于 java -jar）。
